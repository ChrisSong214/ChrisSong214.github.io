Project 4B: Feature Matching and Autostitching

CS 180: Intro to Computer Vision and Computational Photography

Overview: In this project, we implement an end-to-end system for automatically stitching image mosaics following the paper "Multi-Image Matching using Multi-Scale Oriented Patches" (MOPS) by Brown et al. (CVPR 2005). The pipeline automates the manual point clicking from Part 4A by detecting Harris interest corners, spatially distributing them with Adaptive Non-Maximal Suppression (ANMS), extracting normalized 8×8 feature descriptors from 40×40 windows, matching features using Lowe's nearest-neighbor ratio test, and computing robust homographies via 4-point RANSAC.

B.1: Harris Corner Detection & Adaptive Non-Maximal Suppression (ANMS)

The first step identifies salient interest points where the image has sharp gradient variations in multiple directions using the Harris corner response measure. While corner_harris detects thousands of local peaks, they tend to cluster densely in highly textured regions (such as tree foliage or intricate brickwork) while leaving other areas bare.

To produce an even spatial distribution of strong feature points across the entire image, we implement Adaptive Non-Maximal Suppression (ANMS) (Brown et al., Section 3). For each detected corner $x_i$, its suppression radius $r_i$ is defined as the minimum distance to another corner $x_j$ that has significantly larger corner strength:

r_i = min_j ||x_i - x_j||_2    such that    f(x_i) < c_robust × f(x_j),    c_robust = 0.9

If no point $x_j$ satisfies this condition, $r_i = \infty$. All corners are then sorted in descending order of suppression radius $r_i$, and the top $N$ corners (e.g. 500 to 1,000) are retained.

B.2: Feature Descriptor Extraction

For each selected interest point, we extract an axis-aligned 8×8 feature descriptor. Rather than sampling an 8×8 pixel neighborhood directly (which would cover too small an area and be sensitive to high-frequency noise), we sample from a larger 40×40 window centered at the feature point:

  • Anti-Aliasing Filter: We first apply a Gaussian blur ($\sigma = 1.5$) to the image to eliminate high-frequency aliasing before downsampling.
  • Subsampling: The 40×40 window is sampled at 5-pixel intervals (window[2::5, 2::5]) to obtain an 8×8 descriptor patch.
  • Bias / Gain Normalization: Each 8×8 patch $D$ is normalized to zero mean and unit variance:
    D_norm = (D - mean(D)) / (std(D) + 1e-8)
    This provides invariance to affine lighting variations (brightness offset and contrast scale).

B.3: Feature Matching (Lowe's Ratio Test)

To establish correspondences between two images, we compute the pairwise Euclidean distances between all descriptors in Image 1 and Image 2. For each feature in Image 1:

  1. We identify its 1st nearest neighbor (smallest distance $e_{\text{1-NN}}$) and 2nd nearest neighbor (second smallest distance $e_{\text{2-NN}}$) in Image 2.
  2. We compute the distance ratio $r = \frac{e_{\text{1-NN}}}{e_{\text{2-NN}}}$.
  3. If $r < \text{threshold}$ (we use 0.7, consistent with Brown et al. Figure 6b), we declare $(i, \text{1-NN})$ a candidate match. False matches typically have $r \approx 1.0$ because arbitrary patches look equally dissimilar to many background patches, whereas true matches have a distinctively small 1-NN distance.

B.4: 4-Point RANSAC for Robust Homography & Mosaic Stitching

Even after Lowe's ratio test, a small fraction of outlier matches can remain. Because ordinary least-squares homography fitting is highly sensitive to outliers, we implement 4-Point RANSAC (Random Sample Consensus) completely from scratch:

  1. Sample: Randomly select 4 candidate correspondence pairs $(p_1, p_2)$ without replacement.
  2. Hypothesize: Solve for the exact homography $H$ mapping $p_2 \to p_1$ using the 4 pairs.
  3. Evaluate: Project all points $P_2$ by $H$: $\hat{P}_1 = H P_2$. Compute the Euclidean projection error $\epsilon_k = \|\hat{P}_{1, k} - P_{1, k}\|_2$.
  4. Consensus: Count inliers satisfying $\epsilon_k < \text{threshold}$ (3.0 pixels).
  5. Iterate: Repeat for $S = 4,000$ iterations and retain the model yielding the largest inlier set.
  6. Refit: Recompute the final optimal homography $H_{\text{final}}$ using all consensus inliers via linear least squares.

B.5: Bells & Whistles: Rotation Invariance (Oriented Descriptors)

Standard axis-aligned descriptors are not invariant to in-plane image rotation. To achieve rotation invariance as described in Brown et al. (MOPS Section 4):

  • We compute image gradients $I_x, I_y$ on the smoothed image.
  • For each keypoint, we determine the dominant local gradient direction:
    \theta = \text{arctan2}\left(\sum I_y, \sum I_x\right)
  • We rotate the canonical 40×40 sampling grid by angle $\theta$ around the interest point before extracting the 8×8 normalized descriptor using bilinear interpolation.
